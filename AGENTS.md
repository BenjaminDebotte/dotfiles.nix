# Project: NixOS Dotfiles

## AI Agent Guardrails & Conventions
This repository contains a declarative NixOS and Home Manager configuration using Flakes. AI agents operating in this repository must strictly adhere to the following rules.

## Core Philosophy: Declarative over Imperative
- **NEVER** use standard Linux package managers (`apt`, `pacman`, `dnf`, `yum`, etc.).
- **NEVER** suggest imperative configuration changes like writing directly to `/etc/...` or using `systemctl enable`.
- **ALL** changes must be made declaratively via Nix expressions.

## Scope & Structure Boundaries
This repository splits configuration into two main scopes:

1. **`system/` (System-Level NixOS Configuration):**
   - Use for: System services (systemd, ssh, docker), kernel parameters, bootloaders, drivers, display managers (SDDM, GDM), and network configurations.
   - **BANNED:** Never edit `system/hardware-configuration.nix`. This file is generated by NixOS and is machine-specific. Do not touch it.

2. **`home/` (User-Level Home Manager Configuration):**
   - Use for: User-specific programs (CLI tools, browsers), dotfiles (`home/config/`), themes, shell configurations (zsh, bash), and user environments.
   - Files are located in `home/user/` (e.g., `programs.nix`).

**Rule of Thumb for New Additions:**
If a tool requires root access or affects all users, put it in `system/`. If it is a personal tool, editor, or CLI utility, put it in `home/`.

## Execution & Deployment Constraints
- **NEVER** run deployment commands autonomously (e.g., `nixos-rebuild switch`, `home-manager switch`, `nixos-rebuild boot`).
- Applying changes to the live system is strictly the human's job.
- You are allowed to test syntax and evaluate the flake using safe commands like:
  - `nix flake check`
  - `nix-instantiate --parse <file>`

## Formatting
- Format Nix files before presenting changes. While no specific formatter is strictly enforced in the flake yet, you must produce clean, idiomatic Nix code with standard 2-space indentation. 

## Secrets
- **BANNED:** Do not modify, commit, or print secrets, private keys, or passwords.

## Summary Checklist for AI Actions:
1. Did I write declarative Nix code?
2. Did I place the change in the correct folder (`system/` vs `home/`)?
3. Did I avoid touching `hardware-configuration.nix`?
4. Did I stop before running `nixos-rebuild`?
